Criei esta aplicação web para servir como a vitrine digital do negócio da minha família, o Fama Restaurante. O objetivo principal foi aplicar na prática meus conhecimentos de desenvolvimento web, integração de tecnologias e versionamento de código. A plataforma funciona como um cartão de visitas digital interativo, onde os clientes podem explorar o nosso ambiente, com visualizações dinâmicas da da localização, e apresentar um pouco mais sobre a história e cardápio do restaurante.

Para construir a interface visual de forma ágil, utilizei técnicas de vibecoding no front-end, estruturando a base com HTML5, CSS3 e JavaScript. Isso me permitiu focar na integração com o back-end, que foi desenvolvido em Python utilizando o microframework Flask. A ponte entre o Python e o HTML foi feita nativamente através do Jinja2, facilitando a renderização dinâmica e o gerenciamento dos caminhos dos arquivos estáticos.

Caso você queira executar este projeto localmente para testes, é necessário clonar o repositório e acessar a pasta do projeto pelo seu terminal. Em seguida, recomendo a criação e ativação de um ambiente virtual em Python para manter as dependências isoladas. Com o ambiente ativo, basta instalar as bibliotecas listadas no arquivo de requisitos e rodar o arquivo principal da aplicação.
